# 뿌리

사용자만 바꾼다. Claude는 고치자는 제안만 하고 직접 바꾸지 않는다. 규칙이 뿌리와 부딪히면 규칙이 진다.

## 목적

새 프로젝트가 빅테크 상위 수준의 기준으로, 가볍게 시작한다.
