# graphify

판정: 선택
날짜: 2026-10-25
출처: graphifyy (PyPI)

내용: 코드·문서·SQL을 그래프로 만들어 파일을 뒤지는 대신 `graphify query`로 묻는다. 코드는 이 컴퓨터 안에서만 읽는다.
이유: 입력 토큰을 줄이는 쪽이라 효과가 크다. 실행 프로그램이 컴퓨터에 있어야 해서 필수로 못 박지 않는다(P1, P5). 프로그램이 있으면 `setup.sh`가 `graphify install --project`로 프로젝트에 붙인다.
다시 심사할 조건: 설치 없이 쓸 수 있는 방법이 생기면 필수로 올린다.
